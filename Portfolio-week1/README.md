# Personal Portfolio Website

## Project Overview

A responsive personal portfolio website built using HTML5,
CSS3 and JavaScript. The website showcases my skills,
projects and contact information.

## Features

- Responsive design
- Semantic HTML5
- CSS Grid
- Flexbox
- Responsive navigation
- Contact form
- Form validation
- Accessibility support
- Hover effects
- CSS transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
