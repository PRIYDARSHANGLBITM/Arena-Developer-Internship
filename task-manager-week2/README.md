# Interactive Task Manager

## Project Description

A responsive task management application built using HTML5, CSS3 and JavaScript.

## Features

- Add, edit and delete tasks
- Mark tasks as completed
- Filter tasks by All, Active and Completed
- localStorage data persistence
- Task statistics
- Form validation
- Dark/Light mode
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage
- Git

## How to Run

1. Download or clone the repository.
2. Open the `week2-task-manager` folder.
3. Open `index.html` using Live Server.
4. Add and manage your tasks.
