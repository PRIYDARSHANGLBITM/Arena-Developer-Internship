# Blog Management REST API (Week 6)

## Features
- CRUD operations for Blog Posts & Categories
- Custom exception handling (`ResourceNotFoundException`)
- Request Validation using Spring Validation
- Interactive API Documentation with Swagger UI / Open API

## Tech Stack
- Java 17
- Spring Boot 3
- Spring Data JPA
- H2 / PostgreSQL
- Swagger UI (Springdoc)

## Setup & Run Instructions
1. Clone the repository
2. Run `mvn clean spring-boot:run`
3. Open Swagger UI at `http://localhost:8080/swagger-ui/index.html`
